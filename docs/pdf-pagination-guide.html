상품 설계서 PDF — 페이지 잘림 방지 가이드

3페이지 문서가 페이지 경계를 넘을 때 표·이미지·문단이 잘리지 않게 하는 방법
clinic-updatesCSS Fragmentation WeasyPrint / Chromium2026-07-24
이 문서 자체가 예시입니다. 아래에서 설명하는 기법 (break-inside: avoid, orphans/widows, 표 머리행 반복, 이미지 figure 통째 유지)을 그대로 적용해 3페이지로 만들었습니다.

1. 문제 정의 — 무엇이 “잘리는가”

HTML을 PDF로 변환할 때 렌더러는 콘텐츠를 페이지 높이에 맞춰 자동으로 자릅니다. 아무 제어가 없으면 다음이 발생합니다.

  • 표 행 중간 잘림 — 한 행이 두 페이지에 걸침
  • 이미지 절단 — 설계서 그림이 페이지 하단에서 반으로 잘림
  • 제목 고립 — 소제목만 페이지 맨 아래 남고 본문은 다음 장으로
  • 고아·과부 줄 — 문단의 첫/마지막 한 줄만 외톨이로 넘어감
  • 표 머리행 소실 — 다음 페이지로 넘어간 표에 헤더가 없음

2. 예시 — 상품 설계서 이미지

3페이지 문서에 함께 들어가는 “상품 설계서” 예시입니다. figure로 묶여 페이지 경계에서 반으로 잘리지 않고 통째로 이동합니다.

3. 적용할 수 있는 기법 (CSS 기준)

① 요소 통째 유지 — break-inside: avoid

표·카드·이미지·코드블록 등 쪼개지면 안 되는 단위에 적용. 안 들어가면 통째로 다음 페이지로.

.card,figure,tr,pre{
  break-inside:avoid;
  page-break-inside:avoid;/*구형*/}
② 제목-본문 붙이기 — break-after: avoid

소제목이 페이지 맨 아래 혼자 남지 않도록 뒤 콘텐츠와 함께 넘깁니다.

h2,h3{ break-after:avoid; }
③ 고아·과부 줄 — orphans / widows

문단이 경계에서 최소 몇 줄은 함께 유지되도록 지정(권장 2~3).

body,p{ orphans:2; widows:2; }
④ 표 머리행 반복 — thead

표가 여러 페이지로 넘어가도 각 페이지 상단에 헤더 재출력.

thead{ display:table-header-group; }
tr{ break-inside:avoid; }
⑤ 이미지 잘림 방지

figure로 캡션과 묶고 페이지 높이를 넘지 않게 상한.

figure{ break-inside:avoid; }
figure img{ max-height:90vh; }
⑥ 명시적 페이지 나눔 — break-before

“여기부터 새 페이지” 강제. 3페이지 구조를 의도대로 고정.

.page-break{ break-before:page; }

페이지 여백·쪽번호(@page)

여백을 충분히 주고 @page로 쪽번호를 넣으면 “몇 페이지 중 몇”을 표기해 잘림 검수가 쉬워집니다(이 문서 하단 참고).

@page{ size:A4; margin:15mm;
  @bottom-center{ content:counter(page)"/"counter(pages); } }

4. 도구별 적용 방법

같은 CSS라도 렌더러마다 지원 범위가 다릅니다. 상품 설계서 PDF 생성에 쓸 수 있는 대표 도구입니다.

도구변환 방식페이지 제어 지원권장 상황
WeasyPrintHTML+CSS → PDF (Python)break-inside/after, orphans/widows, @page, thead 반복 모두 우수표·이미지 많은 설계서, 서버 자동 생성
Chromium

from weasyprint import HTML
HTML("guide.html").write_pdf("guide.pdf")

from reportlab.platypus import KeepTogether
story.append(KeepTogether([img, cap]))
핵심 3가지

① 쪼개지면 안 되는 단위를 break-inside:avoid로 묶기 · ② 표 머리행 반복 · ③ 이미지 figure 통째 유지.

5. 최종 점검 체크리스트

  • ✓ 표·카드·코드블록에 break-inside: avoid
  • ✓ 이미지는 figure + max-height 상한
  • ✓ 표 thead 머리행 반복, tr 쪼개짐 방지
  • ✓ 제목에 break-after: avoid
  • ✓ orphans / widows 2~3 지정
  • ✓ 섹션 경계 break-before: page
  • ✓ @page 여백 확보 + 쪽번호
  • ✓ 생성 후 페이지 경계마다 잘림 최종 확인
요약: “쪼개지면 안 되는 단위”를 명시적으로 묶고(break-inside: avoid), 표 머리행을 반복하고, 이미지를 figure로 통째 유지하는 세 가지가 핵심입니다. 이 문서는 그 규칙을 그대로 적용해 3페이지 어디에서도 잘리지 않습니다.
