도수치료예약

병원용 도수치료 예약·기록·당직 관리 데스크톱 앱
버전 v1.3.56  ·  기준일 2026-07-24  ·  배포 자동 업데이트(GitHub Pages 매니페스트)  ·  문서번호 PDS-056
도수치료예약은 병원 PC에 설치되어 예약·진료 기록·직원 당직을 한 곳에서 관리하는 앱입니다. 인터넷만 연결되면 클릭 한 번(또는 자동)으로 최신 버전을 무결성 검증과 함께 설치하며, 운영 데이터(clinic.db)는 절대 건드리지 않습니다.
CARE
예약·기록 통합

예약, 진료 기록, 메모를 한 화면에서 입력·조회.

SHIFT
당직 시간 집계

야간당직 퇴근시각 입력과 초과 근무시간 자동 집계.

SAFE
안전한 자동 업데이트

SHA256 검증 후 교체, 기존 데이터 100% 보존.

제품 개요

1. 핵심 기능 (v1.3.56)

ID기능입력·제약비고
F-01기록 탭 메모 칸선택 입력, 최대 200자차트번호 또는 성함은 필수
F-02야간당직 퇴근시각 입력직원·날짜별 시각여러 명이면 각자 다른 시각
F-03야간당직 시간 집계기준(기본 18:30) 초과분자정 넘김 정상 계산
F-04과별 당직 횟수 요약직원별 횟수+시간 표시집계→정산 자동 반영
① 기록 탭 “메모” 칸

차트번호·성함·직원 옆에 메모 칸이 추가됐습니다. 추가 폼·목록 표·수정 창에서 입력·확인할 수 있으며(최대 200자, 선택), 메모만 단독으로는 저장되지 않습니다 — 차트번호 또는 성함은 필수입니다.

② 야간당직 퇴근시각·시간 집계
  • 날짜 설정 창에서 당직 직원을 체크하면 퇴근시각 칸이 나타납니다(직원별 개별 입력).
  • “야간당직 추가”(1명·여러 날짜) 창에서는 선택한 모든 날짜에 공통 퇴근시각을 한 번에 지정.
  • 기준 퇴근시간(관리자 → 시스템 → 운영 시간, 기본 18:30) 초과분을 “야간당직 시간”으로 집계 (예: 홍길동 5회 · 12시간 30분). 자정을 넘겨도 바르게 계산됩니다.
  • 아침·점심당직에는 시간 집계가 적용되지 않습니다(야간당직 전용).

3. 데이터 안전 · 마이그레이션

운영 데이터는 업데이트로 절대 손상되지 않습니다

데이터는 설치 폴더가 아니라 아래 경로에 저장되며, 업데이트는 프로그램(exe·내부 파일)만 교체합니다.

%APPDATA%\도수치료예약\ clinic.db / config.json / schema_version.txt / backups\

4. 사용 가이드

자동 업데이트 설정

관리자 탭의 업데이트 매니페스트 URL 입력란에 아래 주소만(앞뒤 공백 없이) 입력 후 저장하고 “업데이트 확인”을 누르면 됩니다. ZIP 주소·SHA256은 직접 입력하지 않습니다.
